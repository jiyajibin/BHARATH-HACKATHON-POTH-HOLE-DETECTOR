Backend & AI Integration Blueprint

RoadGuard integrates custom AI vision models (such as YOLOv8 or TensorFlow Lite) running on a Python API backend or directly in-browser using WebAssembly/ONNX Runtime.

FastAPI + OpenCV + YOLOv8 Deployment Script 
from fastapi import FastAPI, UploadFile, File
from fastapi.middleware.cors import CORSMiddleware
import cv2
import numpy as np
from ultralytics import YOLO

app = FastAPI(title="RoadGuard AI Detection API")
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])

# Load custom trained pothole detection model
model = YOLO("pothole_yolov8n.pt")

@app.post("/api/v1/detect")
async def detect_potholes(file: UploadFile = File(...)):
    contents = await file.read()
    nparr = np.frombuffer(contents, np.uint8)
    img = cv2.imdecode(nparr, cv2.IMREAD_COLOR)
    
    # Run AI Inference
    results = model(img)
    detections = []
    
    for r in results:
        for box in r.boxes:
            conf = float(box.conf[0])
            if conf > 0.45:
                x1, y1, x2, y2 = map(int, box.xyxy[0])
                # Classify severity by bounding box area/depth
                area = (x2 - x1) * (y2 - y1)
                severity = "Severe" if area > 25000 else ("Moderate" if area > 10000 else "Low")
                
                detections.append({
                    "bbox": [x1, y1, x2, y2],
                    "confidence": round(conf, 2),
                    "severity": severity
                })
                
    return {"detections": detections, "count": len(detections)}

How to connect this web app to your Python server:

  1. Run the FastAPI script using uvicorn main:app --reload.
  2. In index.html, point the canvas processing frame to send image Blobs to http://localhost:8000/api/v1/detect.
  3. Received bounding boxes automatically render on the HUD overlay canvas.
